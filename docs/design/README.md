# Design
- **Authors:** @Githab-capibara

This directory contains **design documents** for TorNet — external research
notes, evaluation records, and pre-decision studies that inform how the
project is built. They answer "what did we learn and why does it shape the
design?" and feed decisions that later land as Architecture Decision Records
in [`adr/`](../adr/).

## Purpose

Where [`architecture/`](../architecture/) describes how the system *is built*
and [`mechanisms/`](../mechanisms/) how each feature *works*, design documents
record the *investigation* behind a decision: external docs research,
evaluated options, and findings that have not (yet) been turned into code or
an ADR. A design note is a research record, not a decision record — a decision
belongs in an ADR.
